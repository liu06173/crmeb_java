
# Java E-Commerce System

### Project Introduction

A Java-based open-source e-commerce solution built with SpringBoot + Vue + uni-app, supporting multi-platform deployment (H5, WeChat Mini Program, Official Account, PC).

#### Tech Stack
- Backend: Java SpringBoot + Mybatis-plus + MySQL + Redis
- Frontend (Admin): Vue + Element UI
- Frontend (Mobile): Uni-app
- Requirements: Java 1.8, MySQL 5.7

#### Project Structure
```
1. admin     WEB Admin Panel (Vue + ElementUI)
2. app       Mobile Shop (UniApp: H5 + WeChat Mini Program)
3. crmeb     Backend API (Java SpringBoot + MybatisPlus)
4. 接口文档   API Documentation
```

#### Core Features
- Product management (SKU, attributes, categories, reviews)
- Order management, user management, shopping cart
- Logistics management, financial statistics
- Multiple payment methods
- Marketing tools: group buying, bargaining, flash sales, coupons, sign-in, points, membership
- Visual page builder with drag-and-drop components

#### Technical Highlights
- SpringBoot framework with RESTful API design
- Spring Security role-based permission control
- Redis queue for high concurrency
- ECharts for data visualization and statistics
- Data export support
