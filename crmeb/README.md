
# Java E-Commerce System

### Introduction

A Java-based open-source e-commerce solution built with Java + Vue + Uni-app, supporting WeChat Official Account, Mini Program, and H5 mobile platforms.

### Tech Stack
~~~
1. Mobile: UniApp development framework (H5, Official Account, WeChat Mini Program)
2. WEB PC Admin: Vue + Element UI
3. Backend: Java SpringBoot + Mybatis-plus + MySQL + Redis
4. Runtime: Linux/Windows with Java environment, MySQL and Redis
5. Requirements: Java 1.8, MySQL 5.7
~~~

### Framework Versions
~~~
1. SpringBoot 2.2.6.RELEASE
2. Maven 3.6.1
3. swagger-bootstrap-ui 1.0
4. Mybatis Plus 3.3.1
5. npm 6
6. node 14
7. vue 2.x
8. element ui 2.13
~~~

### Project Code Packages
~~~
1. admin     WEB Admin Panel (Vue + ElementUI)
2. app       Mobile Shop (UniApp: H5 + WeChat Mini Program)
3. crmeb     Backend API (Java SpringBoot + MybatisPlus)
4. 接口文档   API Documentation
~~~
